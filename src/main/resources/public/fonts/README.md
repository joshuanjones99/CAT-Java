# CAT typography

These original font files are served locally; CAT does not contact a font CDN.

- **Barlow Semi Condensed Semibold**, 600: page, section and dialog headings,
  plus numeric summary values. [Upstream](https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed).
- **Source Sans 3**, variable 200–900: body copy, navigation, fields, tables and
  buttons. [Upstream](https://github.com/google/fonts/tree/main/ofl/sourcesans3).

Retrieved from the Google Fonts repository on 2026-10-22. Original SIL Open Font
License files accompany each family. The Source Sans filename is shortened for
the local URL; the font binary is unmodified. Only upright faces used by CAT are
bundled. CSS uses `font-display: swap` and the shared shell preloads both files.
